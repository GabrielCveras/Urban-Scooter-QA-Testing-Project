# Urban-Scooter-QA-Testing-Project

Projeto de Quality Assurance (QA) realizado durante minha formação em testes de software, com foco em testes funcionais de uma aplicação Web e testes de API/Backend.

O objetivo do projeto foi validar o comportamento da aplicação Urban Scooter com base nos requisitos fornecidos, identificando possíveis falhas e documentando os resultados dos testes.

## 🎯 Objetivos do Projeto

Analisar os requisitos funcionais da aplicação.

Criar casos de teste positivos e negativos.

Validar campos e comportamentos da interface Web.

Realizar testes de compatibilidade entre navegadores.

Testar funcionalidades da API utilizando Postman.

Identificar e documentar bugs.

Registrar resultados e evidências dos testes.

Trabalhar com uma abordagem baseada em requisitos.

# 🌐 Testes Web

Na primeira parte do projeto, realizei testes funcionais na interface Web do Urban Scooter.

## Atividades realizadas:

Análise dos requisitos da aplicação.

Consulta dos layouts no Figma.

Criação de casos de teste positivos e negativos.

Testes dos campos de escolha da estação.

Testes do campo de endereço.

Testes do campo de nome do cliente.

Testes do campo de número de telefone.

Validação das regras de preenchimento dos campos.

Validação do botão para avançar para a próxima página.

Verificação do comportamento da aplicação com dados válidos e inválidos.

## Execução dos testes em:

Google Chrome

Opera

Validação utilizando a resolução especificada no projeto.

Registro dos resultados no Google Sheets.

Identificação e reporte de bugs no Jira.

# 🔌 Testes de API / Backend

Na segunda parte do projeto, realizei testes das funcionalidades de Backend utilizando a API do Urban Scooter.


## Funcionalidades testadas:

Adicionar entregador

Excluir entregador

## Atividades realizadas:

Análise dos requisitos de Backend.

Consulta da documentação da API.

Criação de casos de teste positivos e negativos.

Execução das requisições utilizando Postman.

Validação dos resultados das requisições.

Verificação dos HTTP Status Codes.

Comparação entre resultado esperado e resultado atual.

Registro dos resultados dos testes.

Reporte de bugs encontrados no Jira.
